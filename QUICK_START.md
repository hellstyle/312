# Быстрый старт для новичков

Пошаговая инструкция для настройки системы оффлайн активации.

## 🎯 Что нужно сделать за 5 минут:

### Шаг 1: Получите свой shared_secret (1 минута)

1. Откройте папку Steam:
   - Нажмите Win+R
   - Введите: `%ProgramFiles%\Steam\config\`
   - Нажмите Enter

2. Найдите файл с расширением `.ma` (например: `12345678901234567.ma`)

3. Откройте его в Блокноте

4. Найдите строку `"shared_secret": "..."` и скопируйте значение в кавычках

### Шаг 2: Настройте конфигурацию (1 минута)

1. Откройте файл: `configs/shared_secrets.cfg`

2. Замените данные на свои:
```ini
[мой_аккаунт]
username = ваше_имя_в_steam
shared_secret = ваш_скопированный_shared_secret
platform = steam
description = Мой основной аккаунт
```

Пример:
```ini
[my_steam]
username = steam_player123
shared_secret = wJ4RACRjPJXFPEyPWjHQOx+2T28Sj+HyMA4CmC6Y6yM=
platform = steam
description = Основной аккаунт для продажи
```

### Шаг 3: Примените шаблон (1 минута)

Запустите команду:
```bash
python apply_template.py offline_activation
```

### Шаг 4: Перезапустите бота (1 минута)

Закройте бота и запустите снова через `Start.bat`

### Шаг 5: Протестируйте (1 минута)

1. В чате с ботом отправьте: `!code`
2. Должен прийти Guard код
3. Проверьте, что код работает в Steam

## ✅ Готово!

Теперь ваша система настроена для оффлайн активации игр.

## 📋 Как добавлять аккаунты:

Для каждого нового аккаунта просто добавьте секцию в `configs/shared_secrets.cfg`:

```ini
[аккаунт_2]
username = steam_user2
shared_secret = secret_2_here
platform = steam
description = Второй аккаунт
```

## 🔧 Если что-то не работает:

### Код не генерируется:
1. Проверьте, что shared_secret скопирован правильно
2. Убедитесь, что файл `configs/shared_secrets.cfg` сохранен
3. Перезапустите бота

### Бот не отвечает на !code:
1. Проверьте, что шаблон применен: `python apply_template.py offline_activation`
2. Убедитесь, что вы сделали покупку в тестовом режиме
3. Проверьте логи в папке `logs/`

### Проблемы с shared_secret:
1. Убедитесь, что взяли секрет из правильного maFile
2. Проверьте, что строка полностью скопирована (включая знаки равно)
3. Попробуйте получить новый secret из maFile
