# Шаблон подписок

Этот шаблон предназначен для продажи подписок на стриминговые сервисы и музыкальные платформы.

## Особенности шаблона

### Автоответы
- `!renew` / `продление` - информация о продлении подписки
- `!login` / `логин` - данные для входа
- `!check` / `проверка` - проверка статуса подписки
- `!rules` / `правила` - правила использования
- `!help` / `помощь` - список доступных команд

### Автовыдача товаров
- Настроены специальные ответы для популярных сервисов:
  - Netflix
  - Disney+
  - HBO Max
  - Hulu
  - Spotify Premium
  - Apple Music
  - YouTube Premium
  - Amazon Prime Video
- Включены правила использования для каждого сервиса
- Информация о сроках и продлении подписок

## Переменные

- `$username` - имя покупателя
- `$lot_name` - название подписки/сервиса
- `$product` - данные для входа (логин/пароль)

## Применение шаблона

### Вариант 1: Ручное копирование
1. Скопируйте содержимое `auto_response.cfg` в ваш файл `configs/auto_response.cfg`
2. Скопируйте содержимое `auto_delivery.cfg` в ваш файл `configs/auto_delivery.cfg`
3. Перезапустите бота

### Вариант 2: Автоматическое применение
```bash
python apply_template.py subscriptions
```

## Настройка после применения

1. Проверьте команды автоответа в `configs/auto_response.cfg`
2. Настройте ответы автовыдачи для ваших конкретных сервисов в `configs/auto_delivery.cfg`
3. Создайте файлы с товарами через Telegram бота (команда `/menu` -> `📦 Автовыдача`)
4. Привяжите лоты к автовыдаче через Telegram бота

## Добавление новых сервисов

Для добавления нового сервиса (например, Crunchyroll, Twitch):

1. Добавьте секцию в `auto_delivery.cfg`:
```ini
[Crunchyroll]
response: 🎌 Спасибо за покупку, $username! 🎉

📦 Данные Crunchyroll: $lot_name
$product

📋 Важные правила:
• НЕ меняйте пароль и email
• НЕ добавляйте новые профили
• Используйте ТОЛЬКО один профиль
• При нарушении правил подписка будет отменена без возврата

⏱️ Срок подписки: указан в заказе
🔄 Продление: пишите в чат за 3 дня до окончания
📞 Нужна помощь? Напишите в поддержку!
telegramNotification: 1
```

2. При создании лота на FunPay используйте точное название из конфига

## Рекомендации по формату товаров

Для файлов с товарами используйте следующий формат:

```
Email: example@email.com
Пароль: password123
Срок подписки: до [дата]
```

## Важные рекомендации

### Безопасность
- Всегда используйте надежные пароли
- Регулярно меняйте пароли (по возможности)
- Следите за активностью на аккаунтах
- Отслеживайте количество профилей

### Управление подписками
- Ведите учет сроков подписок
- Напоминайте покупателям о продлении за 3 дня
- Имейте резервные аккаунты на случай блокировки
- Документируйте случаи нарушения правил

### Обслуживание клиентов
- Быстро отвечайте на проблемы с доступом
- Четко объясняйте правила использования
- Предлагайте альтернативы при проблемах
- Сохраняйте историю переписки с покупателями

## Советы

- Используйте разные команды для разных языков покупателей
- Настройте четкие правила для каждого сервиса
- Включите уведомления в Telegram для контроля подписок
- Тестируйте доступ перед продажей
- Создайте систему отслеживания сроков подписок
- Имейте планы на случай блокировки аккаунтов

## Устранение проблем

### Аккаунт заблокирован
1. Проверьте причину блокировки
2. Свяжитесь с поддержкой сервиса
3. Предложите покупателю замену или возврат
4. Обновите товарный файл

### Покупатель нарушил правила
1. Сохраните доказательства нарушения
2. Отмените доступ без возврата
3. Добавьте покупателя в черный список
4. Сообщите о нарушении в поддержку

### Проблемы с доступом
1. Проверьте актуальность данных
2. Предложите альтернативный аккаунт
3. Помогите с восстановлением доступа
4. Обновите товарный файл
