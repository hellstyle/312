# Шаблон цифровых игр

Этот шаблон предназначен для продажи цифровых товаров: ключей активации, игровых аккаунтов, подписок и т.д.

## Особенности шаблона

### Автоответы
- `!key` / `ключ` - получение ключа активации
- `!account` / `аккаунт` - получение данных аккаунта
- `!warranty` / `гарантия` - информация о гарантии
- `!instructions` / `инструкция` - инструкция по активации
- `!help` / `помощь` - список доступных команд

### Автовыдача товаров
- Настроены специальные ответы для разных платформ:
  - Steam ключи
  - Epic Games ключи
  - Origin/EA ключи
  - Uplay/Ubisoft ключи
  - Игровые аккаунты
  - Netflix аккаунты
- Включены инструкции по активации для каждой платформы
- Информация о гарантии для каждого типа товара

## Переменные

- `$username` - имя покупателя
- `$lot_name` - название лота/товара
- `$product` - данные товара (ключ, логин/пароль и т.д.)

## Применение шаблона

### Вариант 1: Ручное копирование
1. Скопируйте содержимое `auto_response.cfg` в ваш файл `configs/auto_response.cfg`
2. Скопируйте содержимое `auto_delivery.cfg` в ваш файл `configs/auto_delivery.cfg`
3. Перезапустите бота

### Вариант 2: Автоматическое применение
```bash
python apply_template.py digital_games
```

## Настройка после применения

1. Проверьте команды автоответа в `configs/auto_response.cfg`
2. Настройте ответы автовыдачи для ваших конкретных товаров в `configs/auto_delivery.cfg`
3. Создайте файлы с товарами через Telegram бота (команда `/menu` -> `📦 Автовыдача`)
4. Привяжите лоты к автовыдаче через Telegram бота

## Добавление новых платформ

Для добавления новой платформы (например, GOG, PlayStation, Xbox):

1. Добавьте секцию в `auto_delivery.cfg`:
```ini
[GOG ключ]
response: 🎮 Спасибо за покупку, $username! 🎉

📦 Ваш GOG ключ: $product

📋 Инструкция по активации:
[Ваша инструкция]

🔒 Гарантия: 24 часа с момента покупки
📞 Нужна помощь? Напишите в поддержку!
telegramNotification: 1
```

2. При создании лота на FunPay используйте точное название из конфига

## Советы

- Используйте разные команды для разных языков покупателей
- Настройте период гарантии под ваш тип товаров
- Добавьте специфические инструкции для каждой платформы
- Включите уведомления в Telegram для контроля продаж
- Тестируйте инструкции перед продажей
