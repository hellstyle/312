# Шаблон Amazing RP

Этот шаблон предназначен для продажи услуг прокачки на сервере Amazing RP с системой FAQ и формой подтверждения заказа.

## Особенности шаблона

### Автоответы (FAQ)
- `!faq` / `faq` - часто задаваемые вопросы
- `!form` / `форма` - форма заказа с инструкциями
- `!price` / `цена` - информация о ценах
- `!rules` / `правила` - правила заказа
- `!help` / `помощь` - список доступных команд

### Ключевая информация FAQ
- **Навыки дальнобоя идут за 1 единицу уровня, а не за 10**
- Перед покупкой необходимо уточнять количество и готовность к оплате
- Объяснение критериев перед оформлением заказа

### Форма подтверждения заказа
Покупатель должен заполнить форму с 4 обязательными вопросами:
1. **Сервер** - название сервера Amazing RP
2. **Уровни** - с какого по какой уровень будет прокачка
3. **Согласие с рисками** - ДА/НЕТ (возможность наказания за нарушение правил сервера)
4. **Согласие с правилами FunPay** - ДА/НЕТ (возврат 50% при частичном выполнении)

### Автовыдача товаров
- Настроены специальные ответы для разных типов услуг:
  - Общая прокачка Amazing RP
  - Навыки
  - Дальнобой (с особым предупреждением о 1 единице уровня)
- Информация о сроках выполнения
- Правила и требования

## Переменные

- `$username` - имя покупателя
- `$lot_name` - название заказа/услуги
- `$product` - детали заказа (сервер, уровни и т.д.)

## Применение шаблона

### Вариант 1: Ручное копирование
1. Скопируйте содержимое `auto_response.cfg` в ваш файл `configs/auto_response.cfg`
2. Скопируйте содержимое `auto_delivery.cfg` в ваш файл `configs/auto_delivery.cfg`
3. Перезапустите бота

### Вариант 2: Автоматическое применение
```bash
python apply_template.py amazing_rp
```

## Настройка после применения

1. **Обновите цены** в командах `!price` и `цена`
2. **Настройте сроки** выполнения в автовыдаче
3. **Добавьте информацию о серверах** в описания
4. **Настройте уведомления** в Telegram для контроля заказов

## Процесс заказа

### Для покупателя:

1. **Изучение FAQ**
   - Отправляет команду `!faq`
   - Изучает информацию о навыках дальнобоя (1 единица уровня)
   - Уточняет детали при необходимости

2. **Заполнение формы**
   - Отправляет команду `!form`
   - Заполняет форму по образцу:
     ```
     Сервер: Emerald
     Уровни: с 1 по 10
     Согласие с рисками: ДА
     Согласие с правилами FunPay: ДА
     ```

3. **Оформление заказа**
   - После заполнения формы покупатель оформляет заказ на FunPay
   - В описании заказа указывает детали из формы

4. **Выполнение заказа**
   - Исполнитель связывается с покупателем
   - Уточняет время выполнения
   - Выполняет прокачку

### Для продавца:

1. **Проверка формы**
   - Проверяйте, что покупатель заполнил форму перед заказом
   - Убедитесь, что он понимает систему подсчета (1 единица уровня)
   - Проверьте согласие с правилами

2. **Обработка заказа**
   - Свяжитесь с покупателем для уточнения времени
   - Выполните прокачку в указанные сроки
   - Сообщите о завершении

3. **Поддержка**
   - Отвечайте на вопросы через команды FAQ
   - Помогайте с заполнением формы
   - Решайте проблемы при выполнении

## Важные правила

### О навыках дальнобоя
- **Критически важно**: Навыки дальнобоя идут за 1 единицу уровня, а не за 10!
- Покупатели часто путаются в подсчете
- Всегда уточняйте количество перед заказом
- Проверяйте правильность понимания

### О рисках
- Покупатели должны понимать возможность наказания от сервера
- Это должно быть явно указано в форме
- Покупатель подтверждает это ДА/НЕТ

### О правилах FunPay
- При частичном выполнении возвращается 50%
- Это правило FunPay, его нельзя изменить
- Покупатель должен явно согласиться

## Устранение проблем

### Покупатель не понимает систему подсчета
1. Отправьте команду `!faq`
2. Лично объясните: "1 единица уровня = 1 уровень навыка"
3. Приведите пример: "с 1 по 10 = 10 единиц = 10 уровней"
4. Попросите подтвердить понимание

### Покупатель не заполнил форму
1. Напомните о необходимости заполнения
2. Отправьте команду `!form`
3. Помогите с заполнением при необходимости
4. Не принимайте заказ без формы

### Спор о количестве уровней
1. Сошлитесь на FAQ и форму
2. Покажите переписку с подтверждением
3. Используйте правила FunPay для решения
4. При частичном выполнении - возврат 50%
