# Шаблон игровой валюты и предметов

Этот шаблон предназначен для продажи игровой валюты, скинов, предметов и других внутриигровых товаров.

## Особенности шаблона

### Автоответы
- `!order` / `заказ` - информация о заказе
- `!status` / `статус` - статус заказа
- `!delivery` / `доставка` - информация о доставке
- `!requirements` / `требования` - требования для получения заказа
- `!help` / `помощь` - список доступных команд

### Автовыдача товаров
- Настроены специальные ответы для разных игр:
  - CS:GO скины
  - CS2 скины
  - Dota 2 предметы
  - Fortnite V-Bucks
  - Roblox Robux
  - GTA Online деньги
  - WoW золото
- Включены требования для получения каждого типа товара
- Информация о времени получения для каждого типа товара

## Переменные

- `$username` - имя покупателя
- `$lot_name` - название лота/товара
- `$product` - данные заказа (инструкции, координаты и т.д.)

## Применение шаблона

### Вариант 1: Ручное копирование
1. Скопируйте содержимое `auto_response.cfg` в ваш файл `configs/auto_response.cfg`
2. Скопируйте содержимое `auto_delivery.cfg` в ваш файл `configs/auto_delivery.cfg`
3. Перезапустите бота

### Вариант 2: Автоматическое применение
```bash
python apply_template.py game_currency
```

## Настройка после применения

1. Проверьте команды автоответа в `configs/auto_response.cfg`
2. Настройте ответы автовыдачи для ваших конкретных игр в `configs/auto_delivery.cfg`
3. Создайте файлы с товарами через Telegram бота (команда `/menu` -> `📦 Автовыдача`)
4. Привяжите лоты к автовыдаче через Telegram бота

## Добавление новых игр

Для добавления новой игры (например, Valorant, Apex Legends):

1. Добавьте секцию в `auto_delivery.cfg`:
```ini
[Valorant скины]
response: 💰 Спасибо за покупку, $username! 🎉

📦 Заказ: $lot_name
$product

📋 Требования для получения:
• Добавьте меня в друзья (Riot ID)
• Укажите ваш Riot ID и тег
• Будьте онлайн в Valorant

⏱️ Среднее время получения: 5-15 минут
🔒 Гарантия: до момента получения товара
📞 Нужна помощь? Напишите в поддержку!
telegramNotification: 1
```

2. При создании лота на FunPay используйте точное название из конфига

## Рекомендации по формату товаров

Для каждого типа товара используйте соответствующий формат в файлах с товарами:

### Для трейд-предметов (CS:GO, CS2, Dota 2):
```
Ссылка на трейд-офер: https://steamcommunity.com/tradeoffer/new/...
Инструкции: Добавьте в друзья и примите трейд
```

### Для кодов подарков (Fortnite, Roblox):
```
Код подарка: XXXX-XXXX-XXXX-XXXX
Инструкция активации: Активируйте в Epic Games
```

### Для внутриигровой валюты (GTA Online, WoW):
```
Сервер: [название сервера]
Фракция: [название фракции]
Имя персонажа: [имя]
Время получения: [указанное время]
```

## Советы

- Используйте разные команды для разных языков покупателей
- Настройте точное время получения для каждого типа товара
- Включите уведомления в Telegram для контроля заказов
- Тестируйте процесс получения перед продажей
- Укажите четкие требования для каждого типа товара
