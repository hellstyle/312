# Шаблон Steam Guard

Этот шаблон предназначен для продажи Steam Guard кодов и Steam аккаунтов с **оффлайн активацией**.

## Особенности шаблона

### Автоответы
- `!code` - основной способ получения Steam Guard кода (оффлайн активация)
- `!steamcode` - альтернативная команда для получения кода
- `!guard` - сокращенная команда для получения кода
- `код` - русская команда для получения кода
- `стим гвард` - альтернативная русская команда
- `!help` / `помощь` - список доступных команд

### Система ограничений
- **3 попытки** запроса кода на покупку
- Автоматическая проверка покупки перед выдачей кода
- Отслеживание оставшихся попыток
- Время действия кода: **30 секунд**

### Автовыдача товаров
- Настроены специальные ответы для Steam аккаунтов
- Интеграция с командой `!code` для получения Guard кода
- Автоматические уведомления в Telegram о выдаче товаров
- Инструкции по оффлайн активации

## Переменные

- `$username` - имя покупателя
- `$lot_name` - название лота/товара
- `$product` - данные товара (логин/пароль или другая информация)
- `$code` - сгенерированный Steam Guard код
- `{attempts}` - количество оставшихся попыток (заполняется автоматически)

## Применение шаблона

### Вариант 1: Ручное копирование
1. Скопируйте содержимое `auto_response.cfg` в ваш файл `configs/auto_response.cfg`
2. Скопируйте содержимое `auto_delivery.cfg` в ваш файл `configs/auto_delivery.cfg`
3. Перезапустите бота

### Вариант 2: Автоматическое применение
```bash
python apply_template.py steam_guard
```

## Настройка после применения

1. Проверьте команды автоответа в `configs/auto_response.cfg`
2. Настройте ответы автовыдачи в `configs/auto_delivery.cfg`
3. Добавьте файлы с товарами через Telegram бота (команда `/menu` -> `📦 Автовыдача`)
4. Привяжите лоты к автовыдаче через Telegram бота
5. Настройте Guard систему (Gmail или shared_secret)

## Оффлайн активация

### Что такое оффлайн активация?
Оффлайн активация позволяет пользователям входить в Steam без постоянного интернет-подключения. Guard код запрашивается только при входе в систему.

### Процесс для покупателя:
1. Покупатель получает данные аккаунта
2. При входе в Steam запрашивается Guard код
3. Покупатель отправляет команду `!code` в чат
4. Бот проверяет покупку и выдает код
5. Покупатель вводит код в течение 30 секунд
6. Доступно 3 попытки для получения кода

## Настройка Guard системы

### Вариант 1: Shared Secret (Рекомендуется)
Shared Secret - это более надежный и быстрый метод, который работает локально без Gmail.

**Преимущества:**
- Не требует Gmail
- Мгновенная генерация кодов
- Работает без интернет-подключения
- Надежнее и быстрее

**Настройка:**
1. Получите `shared_secret` из maFiles вашего Steam аккаунта
2. В коде бота или через консоль добавьте аккаунт:
```python
from shared_secret_guard import get_shared_secret_manager
manager = get_shared_secret_manager()
manager.add_account("username", "shared_secret_here")
```
3. Система автоматически будет использовать shared_secret

### Вариант 2: Gmail (Fallback)
Gmail метод используется как резервный, если shared_secret не настроен.

**Настройка:**
1. Настройте Gmail для получения Guard кодов
2. Убедитесь, что `gmail_guard_integration.py` работает
3. Проверьте, что `purchase_checker.py` отслеживает покупки

## Советы

- Используйте shared_secret для более надежной работы
- Используйте разные команды для разных языков покупателей
- Настройте уведомления в Telegram для контроля продаж
- Проверьте, что Guard код генерируется корректно перед продажей
- Объясняйте покупателям процесс оффлайн активации
- Следите за количеством попыток запроса кода

## Устранение проблем

### Код не выдается (Shared Secret)
1. Проверьте, что аккаунт добавлен в систему
2. Убедитесь, что shared_secret корректный
3. Проверьте логи бота на наличие ошибок

### Код не выдается (Gmail)
1. Проверьте, что покупка зарегистрирована в системе
2. Убедитесь, что Gmail интеграция работает
3. Проверьте логи бота на наличие ошибок

### Превышен лимит попыток
1. Покупатель использовал все 3 попытки
2. Можно сбросить попытки через поддержку
3. Проверьте логи для анализа ситуации

### Код истекает
1. Напомните покупателю использовать код сразу
2. Проверьте синхронизацию времени
3. При использовании shared_secret код должен быть всегда актуален
