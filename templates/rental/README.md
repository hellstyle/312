# Шаблон аренды игр по времени

Этот шаблон предназначен для продажи аренды игр с автоматическим управлением временем сессий.

## Особенности шаблона

### Система аренды
- **Автоматическое создание сессий** при заказе
- **Отслеживание времени** с момента скачивания игры
- **Автоматическое завершение** по истечении времени
- **Управление через команды** в чате

### Команды для аренды
- `!select_game [игра]` - выбор игры для аренды
- `!downloaded` - игра скачана, начинается отсчет времени
- `!rental_status` - проверка статуса аренды
- `!extend [часы]` - продление аренды
- `!help_rental` - справка по аренде

### Система управления сессиями
- Создание сессий при заказе аренды
- Отслеживание выбора игры
- Отслеживание скачивания игры
- Автоматическое завершение по времени
- Сохранение состояния в файл

## Переменные

- `$username` - имя покупателя
- `$lot_name` - название лота/время аренды
- `$product` - данные доступа (логин/пароль)

## Процесс аренды для покупателя

### Шаг 1: Оформление заказа
Покупатель оформляет заказ на аренду игры

### Шаг 2: Получение доступа
Бот автоматически создает сессию аренды и выдает данные аккаунта

### Шаг 3: Выбор игры
Покупатель заходит в аккаунт и выбирает игру:
```
!select_game Cyberpunk 2077
```

### Шаг 4: Скачивание игры
Покупатель скачивает игру и отправляет:
```
!downloaded
```

### Шаг 5: Начало аренды
⏰ С этого момента начинается отсчет времени аренды

### Шаг 6: Проверка статуса
Покупатель может проверить статус:
```
!rental_status
```

### Шаг 7: Продление (опционально)
Если нужно продлить аренду:
```
!extend 2
```

### Шаг 8: Автоматическое завершение
По истечении времени сессия автоматически завершается

## Интеграция с библиотекой Steam

### Автоматическое создание лотов

Система может автоматически создавать лоты на основе игр в вашей библиотеке Steam:

1. **Настройте Steam API:**
   ```ini
   [Steam]
   steam_id = ВАШ_STEAM_ID
   api_key = ВАШ_STEAM_API_KEY
   ```

2. **Запустите сканер:**
   ```python
   from steam_library_scanner import LotCreator
   
   creator = LotCreator(steam_id="ВАШ_ID", api_key="ВАШ_API_KEY")
   lots = creator.create_rental_lots(rental_hours=24, price=100)
   ```

3. **Сгенерированные лоты сохранятся в** `storage/generated_lots.json`

### Предложение игр для аренды

```python
# Получить лучшие игры для аренды
suggested_games = creator.suggest_games_for_rental(limit=10)
```

## Настройка Steam API

### Получение Steam ID
1. Откройте ваш профиль Steam
2. URL содержит ваш Steam ID64
3. Или используйте сервис: https://steamidfinder.com/

### Получение API Key
1. Перейдите на: https://steamcommunity.com/dev/apikey
2. Введите домен вашего сайта (можно любой)
3. Получите API Key

## Особенности оффлайн активации

### Отличие от обычной аренды
- **Обычная аренда**: время начинается с момента заказа
- **Оффлайн активация**: время начинается после скачивания игры

### Как это работает:
1. Покупатель получает доступ к аккаунту
2. Выбирает игру через `!select_game`
3. Скачивает игру и отправляет `!downloaded`
4. ⏰ ТОЛЬКО С ЭТОГО МОМЕНТА начинается отсчет времени
5. Игрок может играть в оффлайн режиме без доступа в интернет

## Устранение проблем

### Сессия не создается
1. Проверьте, что система аренды включена в конфиге
2. Убедитесь, что лот содержит слово "аренда"
3. Проверьте логи на наличие ошибок

### Время не начинается
1. Убедитесь, что покупатель отправил `!downloaded`
2. Проверьте, что игра была выбрана через `!select_game`
3. Проверьте логи системы аренды

### Команды не работают
1. Проверьте, что шаблон применен
2. Убедитесь, что rental_commands.py загружен
3. Перезапустите бота

### Steam API не работает
1. Проверьте Steam ID и API Key
2. Убедитесь, что API Key действителен
3. Проверьте интернет-соединение
