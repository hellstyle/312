# Шаблоны для FunPay Cardinal

Эта директория содержит готовые шаблоны для создания автоматических заказов с автоответами.

## Структура шаблонов

Каждый шаблон содержит:
- `auto_response.cfg` - файл с командами автоответа
- `auto_delivery.cfg` - файл с настройками автовыдачи товаров
- `README.md` - описание шаблона и инструкции

## Использование шаблонов

1. Выберите нужный шаблон из директории
2. Скопируйте содержимое файлов в вашу конфигурацию
3. Настройте параметры под ваши нужды
4. Или используйте скрипт `apply_template.py` для автоматического применения

## Доступные шаблоны

### steam_guard
Шаблон для работы с Steam Guard кодами и Steam аккаунтами.

### digital_games
Шаблон для продажи цифровых товаров (ключи, аккаунты игр).

### game_currency
Шаблон для продажи игровой валюты и игровых предметов.

## Создание собственных шаблонов

Для создания собственного шаблона:
1. Создайте новую директорию в `templates/`
2. Добавьте файлы `auto_response.cfg` и `auto_delivery.cfg`
3. Добавьте файл `README.md` с описанием
4. Используйте переменные в текстах ответов: `$username`, `$lot_name`, `$product`, `$code`
