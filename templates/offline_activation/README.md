# Шаблон оффлайн активации игр

Этот шаблон предназначен для продажи оффлайн активации игр на различных платформах (Steam, Epic Games, Origin, Uplay, Battle.net, Rockstar, Xbox).

## Особенности шаблона

### Автоответы для кодов подтверждения
- `!code` / `код` - основной способ получения кода подтверждения
- `!verify` / `верификация` - код верификации
- `!2fa` / `двухфакторка` - двухфакторный код
- `!help` / `помощь` - список доступных команд

### Система ограничений
- **3 попытки** запроса кода на покупку
- Автоматическая проверка покупки перед выдачей кода
- Отслеживание оставшихся попыток
- Время действия кода: **30-45 секунд**

### Автовыдача доступов
- Настроены специальные ответы для разных платформ:
  - Steam оффлайн активация
  - Epic Games оффлайн активация
  - Origin оффлайн активация
  - Uplay оффлайн активация
  - Battle.net оффлайн активация
  - Rockstar Games оффлайн активация
  - Xbox Game Pass оффлайн активация
- Инструкции по оффлайн активации для каждой платформы
- Интеграция с системой Guard кодов

## Переменные

- `$username` - имя покупателя
- `$lot_name` - название игры/пакета
- `$product` - данные доступа (логин/пароль)
- `$code` - сгенерированный код подтверждения
- `{attempts}` - количество оставшихся попыток (заполняется автоматически)

## Оффлайн активация

### Что такое оффлайн активация?
Оффлайн активация позволяет пользователям играть в игры без постоянного интернет-подключения. Код подтверждения запрашивается только при входе в систему.

### Процесс для покупателя:
1. Покупатель получает данные доступа (логин/пароль)
2. Входит в игровую платформу
3. Переводит платформу в оффлайн режим
4. При запросе кода подтверждения отправляет команду `!code`
5. Бот проверяет покупку и выдает код
6. Покупатель вводит код в течение 30-45 секунд
7. Игра становится доступной в оффлайн режиме

### Поддерживаемые платформы

#### Steam
- Интеграция с Steam Guard
- Оффлайн режим через настройки Steam
- Автоматическое получение кодов из Gmail

#### Epic Games
- Коды подтверждения Epic Games
- Оффлайн режим через Epic Games Launcher
- Поддержка 2FA

#### Origin (EA)
- Коды подтверждения Origin
- Оффлайн режим через Origin клиент
- Интеграция с EA Guard

#### Uplay (Ubisoft)
- Коды подтверждения Uplay
- Оффлайн режим через Uplay клиент
- Поддержка Ubisoft Connect

#### Battle.net
- Коды подтверждения Battle.net
- Оффлайн режим через Battle.net клиент
- Поддержка Blizzard Guard

#### Rockstar Games
- Коды подтверждения Rockstar
- Оффлайн режим через Rockstar Launcher
- Поддержка Social Club

#### Xbox Game Pass
- Коды подтверждения Xbox
- Оффлайн режим через настройки Xbox
- Поддержка Microsoft Guard

## Настройка Guard системы

### Вариант 1: Shared Secret (Рекомендуется)
Shared Secret - это наиболее надежный метод для оффлайн активации. Работает локально без зависимости от внешних сервисов.

**Преимущества:**
- Не требует Gmail
- Мгновенная генерация кодов
- Работает для всех платформ
- Надежнее и быстрее
- Независимость от интернет-соединения

**Настройка:**
1. Получите `shared_secret` из maFiles вашего аккаунта на нужной платформе
2. Добавьте аккаунт в систему:
```python
from shared_secret_guard import get_shared_secret_manager
manager = get_shared_secret_manager()
manager.add_account("platform_username", "shared_secret_here")
```
3. Система автоматически будет использовать shared_secret

### Вариант 2: Gmail (Fallback)
Gmail метод используется как резервный для некоторых платформ.

**Настройка:**
1. Настройте Gmail для получения кодов подтверждения
2. Добавьте паттерны для разных платформ в `gmail_guard_integration.py`
3. Система будет использовать Gmail как fallback

## Добавление новых платформ

Для добавления новой платформы (например, GOG, PlayStation, Nintendo):

1. Добавьте секцию в `auto_delivery.cfg`:
```ini
[GOG оффлайн активация]
response: 🎮 Спасибо за покупку оффлайн активации GOG, $username! 🎉

📝 ДАННЫЕ ДОСТУПА:
$product

🔐 ДЛЯ ПОЛУЧЕНИЯ КОДА ПОДТВЕРЖДЕНИЯ:
Отправьте команду: !code

⚠️ ВАЖНО ДЛЯ ОФФЛАЙН АКТИВАЦИИ:
• Код действителен 30-45 секунд
• Доступно 3 попытки запроса кода
• Используйте код сразу после получения

📋 ИНСТРУКЦИЯ ПО ОФФЛАЙН АКТИВАЦИИ:
1. Войдите в GOG Galaxy с полученными данными
2. Включите оффлайн режим
3. При запросе кода отправьте команду !code
4. Введите полученный код в течение 30-45 секунд

📞 Нужна помощь? Напишите в поддержку!
telegramNotification: 1
```

2. При создании лота на FunPay используйте точное название из конфига

3. Добавьте паттерн для распознавания писем в `gmail_guard_integration.py`:
```python
# В методе fetch_latest_guard_codes добавьте:
search_criteria = f'(FROM "noreply@gog.com" SINCE {since_date})'
```

- Документируйте случаи нарушения правил

### Обслуживание клиентов
- Быстро отвечайте на проблемы с кодами
- Четко объясняйте процесс оффлайн активации
- Предлагайте альтернативы при проблемах
- Сохраняйте историю переписки с покупателями

## Советы

- Используйте разные команды для разных языков покупателей
- Настройте четкие инструкции для каждой платформы
- Включите уведомления в Telegram для контроля доступов
- Тестируйте процесс активации перед продажей
- Создайте систему отслеживания сроков доступа
- Имейте планы на случай блокировки аккаунтов

## Устранение проблем

### Код не выдается
1. Проверьте, что покупка зарегистрирована в системе
2. Убедитесь, что Gmail интеграция работает
3. Проверьте логи бота на наличие ошибок

### Превышен лимит попыток
1. Покупатель использовал все 3 попытки
2. Можно сбросить попытки через поддержку
3. Проверьте логи для анализа ситуации

### Проблемы с конкретной платформой
1. Проверьте инструкцию для конкретной платформы
2. Убедитесь, что оффлайн режим настроен правильно
3. Предложите альтернативный способ активации

### Письма не приходят от платформы
1. Проверьте настройки уведомлений на платформе
2. Убедитесь, что правильный email указан в аккаунте
3. Проверьте папку Спам в Gmail
