# Система шаблонов FunPay Cardinal

Система шаблонов позволяет быстро настраивать автоматические заказы с автоответами для разных категорий товаров.

## 🎯 Для чего нужны шаблоны?

Шаблоны позволяют:
- Быстро настраивать автоответы для новых категорий товаров
- Использовать проверенные конфигурации для разных типов продаж
- Легко переключаться между разными нишами (Steam, игры, валюта и т.д.)
- Сохранять и переиспользовать успешные конфигурации
- Интегрировать со специализированными системами (Guard коды, оффлайн активация)

## 📋 Доступные шаблоны

### Steam Guard (`steam_guard`)

**Для чего:** Продажа Steam Guard кодов и Steam аккаунтов

**Особенности:**
- Множество команд для получения Guard кода (`!code`, `!steamcode`, `код`, `стим гвард`)
- Специальные ответы для Steam аккаунтов
- Интеграция с системой автовыдачи

**Применение:**
```bash
python apply_template.py steam_guard
```

### Цифровые игры (`digital_games`)

**Для чего:** Продажа цифровых товаров (ключи, аккаунты игр, подписки)

**Особенности:**
- Готовые конфигурации для разных платформ (Steam, Epic, Origin, Uplay)
- Инструкции по активации для каждой платформы
- Настройки для аккаунтов разных сервисов (Netflix и т.д.)
- Система гарантий

**Применение:**
```bash
python apply_template.py digital_games
```

### Игровая валюта (`game_currency`)

**Для чего:** Продажа игровой валюты, скинов, предметов

**Особенности:**
- Конфигурации для популярных игр (CS:GO, CS2, Dota 2, Fortnite, Roblox, GTA, WoW)
- Разные способы получения (трейд, коды, внутриигровая передача)
- Требования для каждого типа товара
- Информация о времени получения

**Применение:**
```bash
python apply_template.py game_currency
```

### Подписки (`subscriptions`)

**Для чего:** Продажа подписок на стриминговые сервисы и музыкальные платформы

**Особенности:**
- Готовые конфигурации для популярных сервисов (Netflix, Disney+, HBO Max, Hulu, Spotify, Apple Music, YouTube Premium, Amazon Prime)
- Правила использования для каждого сервиса
- Информация о сроках и продлении подписок
- Система команд для управления подписками

**Применение:**
```bash
python apply_template.py subscriptions
```

### Amazing RP (`amazing_rp`)

**Для чего:** Продажа услуг прокачки на сервере Amazing RP с системой FAQ и формой подтверждения

**Особенности:**
- Система FAQ с автоматическими ответами
- Форма подтверждения с 4 обязательными вопросами
- Автоматическая проверка формы перед заказом
- Специальные предупреждения о навыках дальнобоя (1 единица уровня)
- Интеграция с системой обработки форм

**Применение:**
```bash
python apply_template.py amazing_rp
```

## 🔧 Ручное применение шаблонов

Если вы хотите частично использовать шаблон или объединить несколько шаблонов:

### 1. Копирование автоответов

Откройте файл шаблона `templates/<имя>/auto_response.cfg` и скопируйте нужные секции в ваш `configs/auto_response.cfg`.

### 2. Копирование автовыдачи

Откройте файл шаблона `templates/<имя>/auto_delivery.cfg` и скопируйте нужные секции в ваш `configs/auto_delivery.cfg`.

### 3. Объединение шаблонов

Вы можете объединить несколько шаблонов, копируя секции из разных файлов.

## ✨ Создание собственных шаблонов

### Автоматическое создание

```bash
python create_template.py my_template "Мой шаблон для продажи"
```

Это создаст базовую структуру шаблона в `templates/my_template/`.

### Ручное создание

1. Создайте директорию в `templates/`
2. Добавьте файлы:
   - `auto_response.cfg` - команды автоответа
   - `auto_delivery.cfg` - настройки автовыдачи
   - `README.md` - документация

### Пример структуры шаблона

```ini
# auto_response.cfg
[!command]
response: Ваш ответ здесь
telegramNotification: 1
enabled: 1
```

```ini
# auto_delivery.cfg
[Название лота]
response: Спасибо за покупку, $username!
Вот ваш товар: $product
telegramNotification: 1
```

## 🎨 Переменные в шаблонах

В шаблонах можно использовать следующие переменные:

- `$username` - имя покупателя
- `$lot_name` - название лота/товара
- `$product` - данные товара (логин/пароль, ключ и т.д.)
- `$code` - сгенерированный код (для Steam Guard)

## 🔒 Безопасность и резервные копии

При применении шаблона автоматически создаются резервные копии:

- `configs/auto_response.cfg.backup_YYYYMMDD_HHMMSS`
- `configs/auto_delivery.cfg.backup_YYYYMMDD_HHMMSS`

Вы всегда можете восстановить предыдущую конфигурацию из резервной копии.

## ⚙️ Настройка после применения шаблона

### 1. Проверка конфигурации

Откройте файлы в `configs/` и проверьте настройки:
- `auto_response.cfg` - команды автоответа
- `auto_delivery.cfg` - настройки автовыдачи

### 2. Добавление товаров

Через Telegram бота:
1. Отправьте `/menu`
2. Нажмите `📦 Автовыдача`
3. Создайте файлы с товарами

### 3. Привязка лотов

Через Telegram бота:
1. Отправьте `/menu`
2. Нажмите `📦 Автовыдача`
3. Привяжите лоты к файлам с товарами

### 4. Тестирование

Перед продажей протестируйте:
- Автоответы на команды
- Автовыдачу товаров
- Уведомления в Telegram

## 💡 Советы по использованию

### Для разных языков

Добавляйте команды на разных языках:
```ini
[!code]
response: Code: $code

[код]
response: Код: $code
```

### Для разных категорий

Используйте разные секции в `auto_delivery.cfg` для разных типов товаров:
```ini
[Steam ключ]
response: Инструкция для Steam ключа

[Epic ключ]
response: Инструкция для Epic ключа
```

### Для персонализации

Используйте переменные для персонализации:
```ini
response: Спасибо за покупку, $username! 🎉
Ваш товар: $lot_name
```

## 🐛 Устранение проблем

### Шаблон не применяется

1. Проверьте, что название шаблона указано верно
2. Убедитесь, что файлы шаблона существуют
3. Проверьте права доступа к файлам `configs/`

### Конфигурация не работает

1. Проверьте синтаксис INI-файлов
2. Убедитесь, что включены настройки (`enabled: 1`)
3. Перезапустите бота после изменений

### Хочу вернуть старую конфигурацию

1. Найдите резервную копию в `configs/`
2. Скопируйте её вместо текущего файла
3. Перезапустите бота
