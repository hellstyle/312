# ПРОСТАЯ ИНСТРУКЦИЯ - ГДЕ ВЗЯТЬ SHARED_SECRET

## ШАГ 1: Откройте Steam

1. Запустите Steam
2. Войдите в свой аккаунт

## ШАГ 2: Включите Steam Guard

1. В Steam: `Steam` → `Настройки` → `Учетная запись`
2. Найдите `Steam Guard` и нажмите `Управление защитником...`
3. Выберите `Начать с нуля` (если уже есть Guard, выберите `Удалить защитник Steam Guard` и начните заново)
4. Следуйте инструкциям на экране

## ШАГ 3: Получите shared_secret

Вам нужен специальный файл maFile. Это находится в папке Steam:

**Путь:**
```
C:\Program Files\Steam\config\
```

Там ищите файлы с названием вроде:
```
12345678901234567.ma
```

## ЕСЛИ ТАМ НЕТ ФАЙЛОВ:

Скачайте программу **Steam Desktop Authenticator**:
1. Перейдите на сайт: https://store.steampowered.com/account/privacystatus/
2. Включите Steam Guard
3. Откройте Steam Desktop Authenticator
4. Найдите кнопку `Вернуть резервный код` или похожую
5. Там будет функция экспорта maFile

## ШАГ 4: Получите shared_secret из maFile

1. Откройте файл `.ma` в Блокноте
2. Найдите строку: `"shared_secret": "..."`
3. Скопируйте всё, что в кавычках после `shared_secret:`

## ШАГ 5: Добавьте в конфиг

Откройте файл: `configs/shared_secrets.cfg`

Замените на:
```ini
[мой_аккаунт]
username = ваше_имя_в_steam
shared_secret = ВАШ_СКОПИРОВАННЫЙ_СЕКРЕТ
platform = steam
description = Мой аккаунт
```

## ШАГ 6: Запустите загрузку

```bash
python load_shared_secrets.py
```

## ШАГ 7: Примените шаблон

```bash
python apply_template.py offline_activation
```

## ШАГ 8: Перезапустите бота

Закройте бота и запустите `Start.bat`

## ВСЁ! 

Теперь при команде `!code` бот будет выдавать Guard код мгновенно.

---

Если папка пустая - скачайте Steam Desktop Authenticator, это проще всего!
